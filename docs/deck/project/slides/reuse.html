Bun Rush, the earlier one-player burger arcade game, already solved the hard parts: running MediaPipe in the browser with no install, a gesture interpreter that measures everything in shoulder widths, keyboard and body merged into one intent, a fixed-timestep loop and crisp vector graphics. Unicorn Run keeps all of that and adds what two players and a racer need: two skeletons, a way to tell them apart, racing gestures, and a completely new pseudo-3D renderer.
