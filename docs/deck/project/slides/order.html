Hills hide things for free

Nearer road is painted last, so it covers whatever is behind a crest. No depth buffer needed.

No seams

Each slice overlaps the previous one by one pixel, so no thin lines show between them.

The draw order is the painter’s algorithm: like a painter, start with the background and finish with what is closest. We first go through the slices from near to far to project them and find which ones are hidden. Then we paint from far to near. Because a slice’s trees, rainbows and unicorns are painted right after that slice, and before the nearer slices, a hill in front naturally hides the bottom of a tree behind it. An early version had faint green lines between slices; overlapping each slice by one pixel fixed that.
