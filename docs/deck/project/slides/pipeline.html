FROM PIXELS TO INTENT

Webcam

960 × 540, shown mirrored

MediaPipe

Pose Landmarker, 2 people, GPU

PlayerAssigner

left = P1, right = P2

RunnerGestures

one per player

InputManager

+ keyboard, per player

Race

steer, run, jump, dash

Stays on this computer

The picture is analysed inside the browser (WebAssembly + WebGL). No video is uploaded.

About 30 detections a second

Each camera frame is analysed once. The game still simulates at 60 Hz with the latest result.

No lost jumps

Jump and dash are events: held until the next game tick picks them up, exactly once.

The whole chain runs in the browser. MediaPipe’s Pose Landmarker, the lite model, is shipped inside the project, so nothing has to be installed and no video leaves the machine. We ask it for two people instead of one. Its output goes through three small modules of our own: the PlayerAssigner decides which skeleton is P1 and which is P2, one RunnerGestures per player turns landmarks into steer, run, jump and dash, and the InputManager merges that with the keyboard. The race code never knows where an input came from. If the graphics card is not usable, MediaPipe falls back to the CPU automatically.
