Under the hood

UNICORN RUN

How the game sees two players through one webcam, and how it draws a split-screen rainbow race

A 2-player body-controlled racer
built on Bun Rush · Bianco’s Labs

Unicorn Run is a two-player racing game in the spirit of Mario Kart, but the controller is your body: you run in place to gallop, lean to steer, jump over hurdles and raise both hands for a rainbow dash. This talk has two halves: first how the webcam turns two people into game controls, then how the split-screen pseudo-3D race is drawn.
