RUNNING VS JUMPING

jump line: 0.35 above normal

running bounce: 0.05 to 0.2 peak to peak

JUMP!

hip height over 4 s, in shoulder widths

Run meter: the bounce over the last 0.6 s, mapped from 0.05 (nothing) to 0.2 (flat out).

Jump: hips 0.35 above normal while rising faster than 1.4 per second. A running bounce never gets there.

No flicker: the meter rises fast and falls slowly, so it does not drop between strides.

The tricky part of a running game: running in place also moves your hips up and down, so how do we not jump on every stride? The answer is the size of the movement. Running bounces the hips by a twentieth to a fifth of a shoulder width. A real jump lifts them by more than a third, and quickly. The run meter looks at the peak-to-peak movement over the last 0.6 seconds, which is about one and a half strides, and there is a unit test that runs in place for five seconds and checks that no jump fires.
