Stand side by side, raise both hands, and run.

To play: double-click start.bat, which runs a tiny local web server and opens the browser; nothing to install. The demo address shows two CPU unicorns racing, handy on a projector. The gallery shows every sprite. All the gesture thresholds live in one config file, so tuning for a new room or camera is a one-line change.
