ONE LOOP, THREE STEPS

1

Read bodies

Only when the camera has a new frame: detect, assign to P1 / P2, update both gesture interpreters.

2

Simulate

Fixed steps of 1/60 s from an accumulator: the race runs at the same speed on any monitor.

3

Draw

Once per screen refresh. The Renderer only reads the race; it never changes a rule.

1280 × 720

All drawing uses one fixed logical screen. A single transform scales it to the window and the screen’s pixel density, so it is sharp on any display.

This is the same loop as Bun Rush. The camera, the simulation and the screen all run at different rates, so they are decoupled. Bodies are read at camera speed, about 30 times a second. The simulation always advances in exact sixtieths of a second, so physics and jump timings do not depend on whether your monitor runs at 60 or 144 Hz. Drawing happens once per refresh and is read-only: the renderer could be thrown away and the game would still play.
